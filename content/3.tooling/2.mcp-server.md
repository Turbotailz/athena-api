title: MCP Server
description: This package includes a Model Context Protocol (MCP) server, allowing AI assistants (like Claude or Cursor) to natively query the Overwatch dataset.
---

## Installation

You don't need to install a separate package. The MCP server is included in `athena-api`.

## Configuration

### Claude Desktop

Add the server to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "athena": {
      "command": "npx",
      "args": ["-y", "athena-api"]
    }
  }
}
```

### Cursor

1. Go to **Cursor Settings** > **Features** > **MCP**.
2. Click **Add New MCP Server**.
3. Select **Stdio** type.
4. Enter the command:
   ```bash
   npx -y athena-api
   ```

## Available Tools

The MCP server exposes the following tools to the AI:

- **`search`**: Search for heroes, items, or powers by name or description.
- **`get_hero_stats`**: Get base stats for a specific hero.
- **`get_item_details`**: Get full details for a specific item.
- **`get_power_details`**: Get full details for a specific power.

## Resources

The server also provides direct access to data via resources:

- `overwatch://heroes` - List of all heroes.
- `overwatch://items` - List of all items.
- `overwatch://powers` - List of all powers.
