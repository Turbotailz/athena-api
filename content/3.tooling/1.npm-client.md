## Installation

::code-group
  ```bash [npm]
  npm install athena-api
  ```
  ```bash [pnpm]
  pnpm add athena-api
  ```
  ```bash [bun]
  bun add athena-api
  ```
::

## Usage

Import the `AthenaClient` and create a new instance.

```typescript
import { AthenaClient } from 'athena-api';

const client = new AthenaClient();

// Get all heroes
const heroes = await client.getHeroes();

// Get a specific hero with full details
const ana = await client.getHero('ana', { items: true, powers: true });

// Get items (filtered by type)
const weapons = await client.getItems('weapon');
```

## Accessing Raw Data

If you need the full dataset locally without making API calls (e.g., for a build script), you can import the raw data directly. Note that this will bundle the entire dataset into your application.

```typescript
import { DATA } from 'athena-api/data';

console.log(DATA.heroes);
console.log(DATA.stat_definitions);
```
