# NPM Client

The `overwatch-hero-api` package provides a fully typed TypeScript client for interacting with the API.

## Installation

::code-group
  ```bash [npm]
  npm install overwatch-hero-api
  ```
  ```bash [pnpm]
  pnpm add overwatch-hero-api
  ```
  ```bash [bun]
  bun add overwatch-hero-api
  ```
::

## Usage

Import the `OverwatchHeroClient` and create a new instance.

```typescript
import { OverwatchHeroClient } from 'overwatch-hero-api';

const client = new OverwatchHeroClient();

// Get all heroes
const heroes = await client.getHeroes();

// Get a specific hero with full details
const ana = await client.getHero('ana', { items: true, powers: true });

// Get items (filtered by type)
const weapons = await client.getItems('weapon');
```

## Accessing Raw Data

If you need the full dataset locally without making API calls (e.g., for a build script), you can import the raw data directly. Note that this will bundle the entire dataset into your application.

```typescript
import { DATA } from 'overwatch-hero-api/data';

console.log(DATA.heroes);
console.log(DATA.stat_definitions);
```
