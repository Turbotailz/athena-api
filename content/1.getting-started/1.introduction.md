## What is it?

It provides a REST API to fetch:
- **Heroes**: Base stats, roles, and images.
- **Items**: Descriptions, costs, and stat changes.
- **Powers**: Unique hero abilities and upgrades.
- **Player Stats**: Search profiles and get career statistics.

## Base URL

All API requests should be made to:

```bash
https://athena-api.pages.dev/api
```

## Quick Example

Fetch a specific hero:

```bash
curl https://athena-api.pages.dev/api/heroes/ana
```
