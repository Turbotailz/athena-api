# Introduction

The **Overwatch Hero API** is a community-driven project that provides structured data for Overwatch 2 and the Stadium game mode.

## What is it?

It provides a REST API to fetch:
- **Heroes**: Base stats, roles, and images.
- **Items**: Descriptions, costs, and stat changes.
- **Powers**: Unique hero abilities and upgrades.

## Base URL

All API requests should be made to:

```bash
https://overwatch-stadium-api.pages.dev/api
```

## Quick Example

Fetch a specific hero:

```bash
curl https://overwatch-stadium-api.pages.dev/api/heroes/ana
```
