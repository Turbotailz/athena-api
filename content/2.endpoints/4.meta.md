---
title: Meta

---

::endpoint{method="GET" route="/api/meta"}
::

Get API metadata and statistics definitions.

### Response

```json
{
  "version": "1.0.0",
  "hero_count": 40,
  "item_count": 120,
  "power_count": 85,
  "last_updated": "2023-10-27T10:00:00Z",
  "stat_definitions": {
    "LIFE": "base_hp",
    "Armor": "armor",
    // ...
  }
}
```
