---
title: Items
description: Access data for purchasable items and upgrades.
---

## List Items

::endpoint{method="GET" route="/api/items"}
::

Retrieve a list of all items.

### Query Parameters

::field-group
  ::field{name="type" type="string"}
    Filter by upgrade type (e.g., `weapon`, `ability`).
  ::
  ::field{name="rarity" type="string"}
    Filter by rarity (e.g., `common`, `rare`, `legendary`).
  ::
::

### Example Request

::code-group
  ```bash [cURL]
  curl https://athena-api.pages.dev/api/items?type=weapon
  ```

  ```js [JavaScript]
  const response = await fetch('https://athena-api.pages.dev/api/items?type=weapon');
  const data = await response.json();
  ```
::

### Response Structure

Returns an array of Item objects.

```json
[
  {
    "id": "heavy_pulse_rifle_mk2",
    "name": "Heavy Pulse Rifle Mk. II",
    "cost": 1500,
    "rarity": "rare",
    "upgrade_type": "weapon",
    "is_universal": true,
    "hero": null,
    "stat_changes": {
      "damage": 10
    }
    // ...
  }
]
```

## Get Item Details

::endpoint{method="GET" route="/api/items/:id"}
::

Retrieve detailed information for a specific item.

### Path Parameters

::field-group
  ::field{name="id" type="string" required}
    The item's unique identifier.
  ::
::

### Response

Returns a single Item object.

```json
{
  "id": "heavy_pulse_rifle_mk2",
  "name": "Heavy Pulse Rifle Mk. II",
  "description": "Increases weapon damage.",
  "cost": 1500,
  // ...
}
```
