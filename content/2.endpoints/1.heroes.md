---
title: Heroes
description: Access data for all Overwatch heroes available in the mode.
---

## List Heroes

::endpoint{method="GET" route="/api/heroes"}
::

Retrieve a list of all heroes.

### Query Parameters

::field-group
  ::field{name="role" type="string"}
    Filter by role (`tank`, `damage`, `support`).
  ::
::

### Example Request

::code-group
  ```bash [cURL]
  curl https://athena-api.pages.dev/api/heroes?role=tank
  ```

  ```js [JavaScript]
  const response = await fetch('https://athena-api.pages.dev/api/heroes?role=tank');
  const data = await response.json();
  ```
::

### Response Structure

Returns an array of Hero objects.

```json
[
  {
    "id": "ana",
    "name": "Ana",
    "role": "support",
    "stadium": true,
    "image_url": "...",
    "base_stats": { ... },
    "item_ids": ["...", "..."],
    "power_ids": ["...", "..."]
  }
  // ...
]
```

## Get Hero Details

::endpoint{method="GET" route="/api/heroes/:id"}
::

Retrieve detailed information for a specific hero.

### Path Parameters

::field-group
  ::field{name="id" type="string" required}
    The hero's unique identifier (lowercase, e.g., `ana`).
  ::
::

### Query Parameters

::field-group
  ::field{name="expand" type="string"}
    Comma-separated list of related resources to embed. Options: `items`, `powers`.
  ::
::

### Example Request

::code-group
  ```bash [cURL]
  curl https://athena-api.pages.dev/api/heroes/ana?expand=powers
  ```

  ```js [JavaScript]
  const response = await fetch('https://athena-api.pages.dev/api/heroes/ana?expand=powers');
  const data = await response.json();
  ```
::

### Response

Returns a single Hero object. If expanded, `items` and `powers` arrays will contain full objects instead of just IDs.

```json
{
  "id": "ana",
  "name": "Ana",
  "role": "support",
  "powers": [
    {
      "id": "nano_boost",
      "name": "Nano Boost",
      // ...
    }
  ]
  // ...
}
```
