# Powers Endpoints

Access data for hero powers and abilities.

## List Powers

::endpoint{method="GET" route="/api/powers"}
::

Retrieve a list of all powers.

### Query Parameters

::field-group
  ::field{name="type" type="string"}
    Filter by upgrade type (e.g., `tech`, `biotic`).
  ::
::

### Example Request

::code-group
  ```bash [cURL]
  curl https://overwatch-hero-api.pages.dev/api/powers
  ```

  ```js [JavaScript]
  const response = await fetch('https://overwatch-hero-api.pages.dev/api/powers');
  const data = await response.json();
  ```
::

### Response Structure

Returns an array of Power objects.

```json
[
  {
    "id": "biotic_grenade",
    "name": "Biotic Grenade",
    "upgrade_type": "biotic",
    "stat_changes": { ... }
    // ...
  }
]
```

## Get Power Details

::endpoint{method="GET" route="/api/powers/:id"}
::

Retrieve detailed information for a specific power.

### Path Parameters

::field-group
  ::field{name="id" type="string" required}
    The power's unique identifier.
  ::
::

### Response

Returns a single Power object.

```json
{
  "id": "biotic_grenade",
  "name": "Biotic Grenade",
  "description": "Throws a grenade that heals and damages.",
  // ...
}
```
